# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run setup        # First-time setup: install deps + prisma generate + migrate
npm run dev          # Dev server (Next.js + Turbopack) at http://localhost:3000
npm run build        # Production build
npm run lint         # ESLint
npm run test         # Run all tests (Vitest)
npm run db:reset     # Wipe and re-run all DB migrations
```

Run a single test file:
```bash
npx vitest src/lib/transform/__tests__/jsx-transformer.test.ts
```

> **Do not run `npm audit fix`.** Dependencies are pinned to specific compatible versions. Audit warnings are cosmetic; running the fix can break the app.

## Environment

Copy `.env.example` to `.env`. Set `ANTHROPIC_API_KEY` to a real key from console.anthropic.com. If the key is missing or still the placeholder `your-api-key-here`, the app falls back to `MockLanguageModel` in `src/lib/provider.ts`, which returns canned components.

## Architecture

### Virtual file system

All generated files live **in memory only** — nothing is written to disk. `VirtualFileSystem` (`src/lib/file-system.ts`) is the core class. It serializes to `Record<string, FileNode>` for storage in SQLite and deserializes back on load.

`FileSystemContext` (`src/lib/contexts/file-system-context.tsx`) wraps the VFS in React state. It exposes `handleToolCall()`, which processes AI tool calls (`str_replace_editor`, `file_manager`) and increments `refreshTrigger` to force re-renders downstream.

### AI chat pipeline

`POST /api/chat` (`src/app/api/chat/route.ts`) receives messages + the serialized file system. It reconstructs a `VirtualFileSystem`, calls `streamText` (Vercel AI SDK) with two tools:

- `str_replace_editor` — create / str_replace / insert in virtual files
- `file_manager` — rename / delete virtual files

The system prompt (`src/lib/prompts/generation.tsx`) is sent with `cacheControl: ephemeral` for prompt caching. On stream finish, if a `projectId` is present and the user is authenticated, messages and file system state are persisted to the DB.

### Live preview

`PreviewFrame` (`src/components/preview/PreviewFrame.tsx`) renders an `<iframe srcdoc>`. On every `refreshTrigger` change it calls `createImportMap` (`src/lib/transform/jsx-transformer.ts`), which:

1. Babel-transforms every `.jsx/.tsx/.ts/.js` file to a blob URL (using `@babel/standalone` in the browser)
2. Resolves third-party package imports to `https://esm.sh/<package>`
3. Stubs missing local imports with placeholder React components
4. Collects CSS into an inline `<style>` block
5. Serves Tailwind via CDN script tag

Entry point resolution order: `/App.jsx` → `/App.tsx` → `/index.jsx` → `/index.tsx` → `/src/App.jsx` → first `.jsx/.tsx` found.

### Auth

Custom JWT auth (`src/lib/auth.ts`) using `jose`. Sessions are stored as an httpOnly cookie (`auth-token`, 7-day expiry). No NextAuth. Anonymous users can use the app freely; only authenticated users get project persistence.

### Database

SQLite via Prisma. Schema in `prisma/schema.prisma`. Two models:

- `User` — email + bcrypt password
- `Project` — `messages` (JSON string) + `data` (serialized VFS JSON string). `userId` is optional to support anonymous projects.

`src/generated/prisma/` is auto-generated by Prisma — do not edit manually. After changing `schema.prisma`, run `npx prisma migrate dev`.

### Path alias

`@/` maps to `src/`. Tests use Vitest + jsdom + `@testing-library/react`. Test files live in `__tests__/` subdirectories next to the code they test.
